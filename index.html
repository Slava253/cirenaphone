📟 НАСТРОЙКА ТЕРМИНАЛА

Введите ID терминала один раз. Он запомнится, и при следующем открытии кассы подключаться не придётся.

Как это работает:
1. На телефоне-терминале создайте терминал — получите 4-значный ID
2. Введите его здесь и нажмите «Сохранить»
3. При оплате картой сумма уйдёт на терминал
4. PIN нужен только если сумма больше 1000 ₽ — клиент вводит любой 4-значный PIN
